# Plan

この依頼では、計画を示すところまでを行う。

- ファイルを編集しない。コミット、push、依存関係の追加など、状態を変えるコマンドも実行しない。読む、検索する、既存の検査を実行して確かめる、までにとどめる
- 要件に不明な点があれば、計画を書く前に質問する
- 計画には、目的、変更するファイルと変更の内容、作業の順番、確かめるために実行する検査、リスクと未決事項を書く
- 計画を示したら止まり、承認を待つ。承認されるまで実装を始めない
